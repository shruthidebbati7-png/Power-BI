# Power BI Sales Dashboard
![Power BI Sales Dashboard](<Power BI dashboard.png>)

📊 Project Overview

This project is an interactive Power BI Sales Dashboard created to analyze sales performance and generate meaningful business insights from sales data.

The dashboard provides a clear view of key sales metrics and helps identify trends and patterns across different categories.

🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning & Transformation
- Data Visualization

📈 Dashboard Features

- Sales performance analysis
- Interactive charts and visualizations
- Category-wise analysis
- Trend analysis
- KPI-based reporting
- Interactive filters and slicers

🔍 Key Insights

The dashboard helps users understand sales performance, identify important trends, and compare different aspects of the business using interactive visualizations.

📁 Project Files

- PowerBI.pbix — Power BI dashboard project file

🎯 Objective

The objective of this project is to transform raw sales data into an interactive and easy-to-understand dashboard that supports data-driven decision making.
